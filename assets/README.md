# Project Assets Directory

This directory stores project diagrams, architecture mockups, screenshots, and visual documentation for presentation slides.

Suggested files:
- `architecture_diagram.png`: High-level system architecture schematic.
- `dashboard_preview.png`: Full dashboard screenshot showing real-time telemetry.
- `process_state_diagram.png`: Process lifecycle finite state machine (FSM).
- `rbac_matrix.png`: Security access control matrix diagram.
